# Contribuindo com o Barber Hub

1. Crie uma branch para a tarefa.
2. Não edite migrations antigas já aplicadas; crie uma nova.
3. Não envie `.env`, chaves ou dados reais de usuários.
4. Faça alterações pequenas e verificáveis.
5. Rode `npm run check` e `python scripts/validate_project.py`.
6. Atualize documentação e mapa de navegação quando o fluxo mudar.
7. Descreva no commit o comportamento alterado, não apenas os arquivos.
